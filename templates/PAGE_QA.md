## Answer quality

- [ ] Direct answer appears near top.
- [ ] Fit state matches calculated dimensions.
- [ ] Required/available dimensions agree with diagram.
- [ ] Assumptions are visible.
- [ ] Market/geography is explicit where relevant.
- [ ] Sourced vs derived values are not conflated.

## UX/accessibility

- [ ] Works at narrow mobile width.
- [ ] Works at desktop width.
- [ ] Keyboard interaction works.
- [ ] Result does not depend on color.
- [ ] Diagram has text equivalent.
- [ ] Unit toggle preserves canonical result.

## SEO/content

- [ ] Unique title.
- [ ] One H1.
- [ ] Canonical correct.
- [ ] Description useful/non-duplicated.
- [ ] Breadcrumb correct.
- [ ] Related links resolve and are relevant.
- [ ] Page has differentiated utility beyond prose.
- [ ] Indexable publication status agrees with canonical and sitemap; lastmod is editorially accurate.
- [ ] Metadata and breadcrumb JSON-LD match the visible page and validate.
- [ ] Visible key answer and crawlable `<a href>` links exist in prerendered HTML.
- [ ] Distinct search intent / SERP gap recorded with evidence in page brief.
- [ ] Correct source provenance and market standard visible.

## Static resilience

- [ ] Principal answer remains useful with JS disabled.
- [ ] No runtime API required.
